**材料与方法**

原始材料为用户提供的《【中文配音】LLM提示词工程实战全31讲：LangChain模板⧸自动评测⧸红队安全⧸CI-CD，从手写Prompt到工程化量产》课程原视频（本地资料，未随仓库分发）。共 31 个 1920×1080 视频，合计 8,159.31 秒，约 135 分 59 秒。视频有画面内嵌的中英文字幕，没有可直接提取的字幕轨。

1. 每秒采样 2 帧，裁取底部字幕区域，对黄色、青色字幕做颜色分离；用精确图像摘要合并完全相同的图像。
2. 使用 Windows 自带的 `zh-Hans-CN` OCR 识别中文。第二次识别按字高过滤较小的背景代码，分析阶段曾保留原始 OCR 文字用于核对。
3. 合并时间相邻、文字近似重复的结果，并保存不同识别版本。生成的字幕文字是机器稿，不是人工校订逐字稿。
4. 每约 8 秒提取完整画面，用 `en-US` OCR 建立代码和幻灯片索引。关键结论重新对照原图，不把屏幕 OCR 当作可运行源码。
5. 通读全部 31 讲字幕稿，将课程做法对应到当前优化器；涉及库接口和 GitHub 行为的判断另外查阅官方资料。
